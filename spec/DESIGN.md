# Дизайн SK DESIGN

## Цель

Главная продаёт создание сайтов через сами работы. Основа — актуальная белая галерея Obys, не старый тёмный сайт Obys с огромным рекламным заголовком. Сохрани много воздуха, асимметрию, спокойную типографику и движение изображений внутри почти неподвижного интерфейса.

Главный визуальный файл — [target-desktop.png](../reference/target-desktop.png), 1536×1024. Это изображение направления, а не готовая страница, которую можно положить фоном. Названия, подписи, ссылки, логотип, фильтры и изображения нужно сверстать отдельно.

## Desktop: ориентиры при 1536×1024

| Элемент | Положение и размер на макете |
|---|---|
| Логотип | x≈50, y≈15; видимый знак около 105×58 px |
| Контакт | справа сверху, отступ справа ≈50 px; базовая линия около y=49 |
| Список | x≈50, заголовок y≈337; строки через ≈33 px |
| Активное превью | x≈359, y≈262, ширина≈819, высота≈430 px |
| Угловые отметки | на 14–15 px снаружи активного превью; штрих около 23 px |
| Название справа | x≈1218, y≈335; SF DIAMONDS около 38 px |
| Категория и ссылка | x≈1225, y≈426 и y≈470 |
| Соседние кадры | меньше активного; выше и ниже; частично уходят за экран |

Координаты приблизительные: визуально сопоставь результат с изображением. На других desktop-размерах сохраняй соотношение центральной галереи, боковых областей и пустоты. Не сжимай подписи до микроскопического размера. При уменьшении ширины переходи к мобильной композиции.

Белый фон #fff; основной текст почти чёрный; вторичный — холодный серый. Лаймовый квадрат у активного пункта — небольшой акцент, примерно 10×10 px. Не делай зелёные заливки кнопок и большие декоративные акценты. Фактура генерации на макете не требует фонового шума на сайте.

Шрифт — нейтральный гротеск с подходящей кириллицей. У референса в computed style виден собственный шрифт Obys; его файл в пакет не включён. Подбери доступный шрифт по ширинам и начертаниям, подключи локально с лицензией. Не заявляй точное совпадение шрифта до сравнения. Крупные заголовки проектов не должны разваливаться при длинном названии.

## Что оставить

- SK DESIGN слева сверху, «Обсудить проект ↗» справа сверху.
- «ПРОЕКТЫ / 16», нумерованный список, выделение текущей работы.
- Вертикальную галерею, крупную активную работу, соседние превью.
- Тонкие прямоугольные угловые отметки вокруг активного кадра.
- Название, категорию, короткую линию и «Смотреть кейс ↗» справа.

## Что удалить окончательно

Не возвращай слоган возле логотипа, вертикальный разделитель, пункты «Работы» и «Подход», «Все проекты», нижний блок «Сайт для вашего бизнеса» со вторым контактом, переключатель видов и угловой счётчик «01 / 16». Нижние области остаются пустыми. Заголовок списка «ПРОЕКТЫ / 16» остаётся. Исходное указание об удалениях: [REMOVED-AREAS.md](../reference/REMOVED-AREAS.md).

У Obys есть режимы Vertical / Horizontal / Grid, часы, текст о студии, контактный блок и авторский знак. В SK DESIGN их добавлять не нужно: у нас уже есть свой утверждённый состав. Круглые скобки Obys заменены тонкими уголками из макета SK DESIGN.

## Чёрно-белые неактивные проекты — требование владельца

Используй оригинальные цветные снимки. Неактивный кадр: `filter: grayscale(1)`, opacity ориентировочно 0.45–0.6. Активный: `grayscale(0)`, opacity 1. Подбери приглушение так, чтобы соседние сайты были узнаваемы и не спорили с центральным.

При входе в центральную область изображение плавно получает цвет; при выходе теряет. Смена не должна мигать на границе двух проектов. Переход цвета около 350–500 ms — стартовая настройка. На touch цвет определяется положением, а не hover. Hover на desktop может слегка усилить видимость соседа, но не менять выбранный проект и подпись без его выбора.

В статичном макете соседние кадры цветные. Последнее сообщение владельца о чёрно-белом фильтре имеет приоритет над этой деталью изображения.

## Реальные изображения

Для галереи используй `gallery_cover` из portfolio.json. Для NAVAT выбран отдельный интерьерный кадр, близкий к макету; исходная обложка вступления также сохранена. Не пересобирай SF Diamonds из текста и кольца: это превью готового сайта внутри нового портфолио. Пропорции и кроп разрешено аккуратно подстроить под композицию, текст внутри скриншота нельзя растягивать.

Макет содержит условную расстановку соседних работ. Реальная лента и список обязаны следовать одному `gallery_order`; не подменяй изображения ради одного кадра. Первый выбранный проект — SF Diamonds. Все 16 доступны через скролл и список, даже если в исходном макете показано шесть названий.

Прозрачный логотип содержит поля. Перед production аккуратно обрежь PNG по alpha, сохрани оригинал. Это растровый знак, SVG в пакете нет. Не используй белую версию как огромную картинку с полями. Логотип ведёт на главную.
