# Ushoo

[Открыть сайт](https://ushoo.vercel.app)

## Короткое описание для карточки

Англоязычный сайт агентства TikTok Shop с услугами для продавцов и инфлюенсеров.

## Описание проекта

Сайт Ushoo представляет услуги по запуску и продвижению магазинов в TikTok Shop. Главная для продавцов раскрывает направления работы, процесс, примеры результатов и условия сотрудничества; отдельная ссылка ведёт к версии для инфлюенсеров.

## Что видно на сайте

- Разделы для sellers и influencers
- Карточки услуг
- Описание этапов сотрудничества
- Блок кейса
- Кнопки обращения и записи на звонок

## Визуальная подача

Белый фон, розово-фиолетовые градиенты, крупные дуги и контрастные цветные карточки.

## Сведения для агента

Проект включён по списку владельца портфолио. Описания выше составлены по публичному интерфейсу, просмотренному 18 октября 2026 года. Они описывают сайт; точный вклад автора пока не установлен.

- Роль автора, авторство дизайна и состав команды: уточнить.
- Стек, сроки, дата запуска и коммерческий статус: уточнить.
- Метрики результата разработки: не предоставлены.

Показатели роста в маркетинговых блоках не подтверждают результат разработки сайта и не должны превращаться в метрики портфолио.

Функции перечислены по видимому интерфейсу. Формы не отправлялись, покупки и бронирования не совершались, в закрытые разделы не входили. Скриншоты фиксируют desktop-вид; обычный кадр около 1280 × 720 px. Точные размеры файлов указаны выше. Mobile-вид не снимался.
