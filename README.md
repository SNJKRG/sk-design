# SK DESIGN — пакет для Claude Code

Внутри — материалы для реализации портфолио студии с арт-дирекшном актуального [Obys](https://obys.agency/), последним макетом SK DESIGN и 16 проектами. Контакт: [@snj_krg](https://t.me/snj_krg).

## Как передать в облачную среду

1. Распакуй ZIP в рабочую папку репозитория, доступного Claude Code. Если интерфейс облачной среды не принимает ZIP, распакуй его перед добавлением файлов в репозиторий.
2. Передай текст [PROMPT-FOR-CLAUDE.md](PROMPT-FOR-CLAUDE.md). Файл [CLAUDE.md](CLAUDE.md) содержит постоянные инструкции для проекта.
3. Попроси агента выполнить реализацию и проверки до конца. Пакет не зависит от путей на компьютере владельца.

Это комплект материалов и задания. Исходного кода будущего сайта и исходного кода Obys в нём нет. Снимки проектов — desktop; адаптив нового портфолио нужно реализовать и проверить отдельно. Видеозаписи референса не приложены: до реализации агент должен снять их, если его облачная среда поддерживает браузер.

На невыбранных проектах обязателен чёрно-белый фильтр, активная работа остаётся цветной. Детали студии и Telegram уже подтверждены. Неизвестные роли, метрики и авторство в публичные кейсы не подставлять.
